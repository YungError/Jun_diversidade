# 🏳️‍🌈 PrideHub - Comunidade LGBT+ Inclusiva

Um site informativo e interativo dedicado à comunidade LGBTQIAPN+, com foco especial em pessoas agênero. Criado para o Projeto de Mês da Diversidade da ETEC.

## 📋 Características Principais

✅ **Home Interativa** - Apresentação colorida com mascote animado
✅ **Educação LGBTQIAPN+** - Explicação detalhada de cada letra da sigla
✅ **Página Agênero Completa** - Informações, curiosidades, personalidades famosas
✅ **Sistema de Eventos** - Visualização, filtragem e criação de eventos
✅ **Perfis de Usuários** - Criação e edição de perfis com informações pessoais
✅ **Design Responsivo** - Funciona perfeitamente em celulares e desktops
✅ **Mudança Dinâmica de Cores** - O site muda de cor conforme você navega
✅ **Interface Inclusiva** - Linguagem acessível e design amigável

## 🎨 Design e Cores

### Tema Rainbow (Padrão)
- Cores: Vermelho, Laranja, Amarelo, Verde, Azul, Roxo
- Usado na maioria das seções

### Tema Agênero
- Cores: Preto, Cinza, Branco e Roxo
- Ativado automaticamente na página "Agênero"

## 🚀 Como Usar

### 1. Abrir o Site Localmente
- Descarregue o arquivo `index.html`
- Abra em qualquer navegador (Chrome, Firefox, Safari, Edge)
- Não requer instalação ou dependências externas

### 2. Navegar pelo Site
- **Home** - Página inicial com informações gerais
- **Sobre LGBTQIAPN+** - Explicação de cada letra da sigla
- **Agênero** - Página dedicada ao gênero agênero
- **Eventos** - Visualize e filtre eventos por categoria
- **Criar Evento** - Formulário para criar novos eventos
- **Meu Perfil** - Visualize e edite seu perfil de usuário

### 3. Seções Principais

#### 📚 Sobre LGBTQIAPN+
Explica cada letra com clareza e respeito:
- **L** - Lésbica
- **G** - Gay
- **B** - Bissexual
- **T** - Transgênero/Transexual
- **Q** - Queer
- **I** - Intersexo
- **A** - Assexual/Agênero
- **P** - Pansexual
- **N+** - Não-binário e outras identidades

#### 🏳️‍⚧️ Página Agênero (DESTAQUE!)
Informações detalhadas sobre identidade agênero:
- Definição formal e acessível
- Características principais
- Significado das cores da bandeira agênero
- Curiosidades fascinantes
- Personalidades agênero conhecidas
- Slogans e mantras inspiradores
- Por que a identidade agênero importa

#### 🎉 Sistema de Eventos
- **Galeria de Eventos** - Veja eventos próximos
- **Filtros** - Todos, Paradas, Workshops, Festas, Palestras
- **Criar Evento** - Formulário completo com:
  - Nome e descrição do evento
  - Categoria e data/horário
  - Local e tipo de entrada
  - Preço e limite de participantes
  - Tags e regras do evento

#### 👤 Perfil de Usuário
Crie e personalize seu perfil com:
- Informações básicas (nome, email, localização)
- Identidade e orientação sexual
- Pronomes e bio pessoal
- Interesses e tags de personalidade
- Links para redes sociais
- Controles de privacidade
- Badges e conquistas

2. **Filtros de Eventos** - Selecione categorias para ver eventos específicos
3. **Formulários Funcionais** - Crie eventos e perfis (feedback visual)

## 📖 Como Fazer Upload no GitHub

### Opção 1: Via Comando Git (Recomendado)

```bash
# 1. Crie um repositório no GitHub (https://github.com/new)
# 2. Clone o repositório localmente
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio

# 3. Copie o arquivo index.html para a pasta
cp /caminho/para/index.html .

# 4. Adicione e commit
git add index.html
git commit -m "Adicionar site PrideHub - Comunidade LGBTQ+"

# 5. Faça push
git push origin main
```

### Opção 2: Diretamente no GitHub

1. Vá para https://github.com/novo-repositório
2. Clique em "Add file" → "Upload files"
3. Arraste o arquivo `index.html`
4. Escreva a mensagem de commit
5. Clique em "Commit changes"

### Opção 3: GitHub Pages (Hospedagem Gratuita)

1. Suba o arquivo para o GitHub (como acima)
2. Vá para "Settings" → "Pages"
3. Selecione "Branch: main" como fonte
4. Seu site será hospedado em: `https://seu-usuario.github.io/seu-repositorio`
